# v0.1 产品契约

> **English** | [简体中文](product-contract.md)

## 名称

`mcp-ward`

## 职责

给定两份 MCP 工具表面，为协议调用方和 Agent 行为两个方向对变化进行分类。
首个版本是一个离线、确定性的检查工具；它从不调用 LLM，也从不需要云账号。

## 目标用户

- MCP Server 维护者
- 带类型的 Agent 客户端维护者
- 评审工具表面 Pull Request 的团队

## 成功标准

用户可以保存两份真实的 `tools/list` 文档，跑一条本地命令，在不到一分钟内
理解这次变更为何有风险，并在 CI 中拿到一个确定性的非零退出码。

## 设计承诺

1. **不静默丢失：** 未知的工具字段和不受支持的 schema 关键字会被保留或显式呈现。
2. **两个轴：** 协议兼容性和 Agent 行为分别报告。
3. **一个引擎：** profile 是同一份 finding 流之上的卡点，而不是彼此独立的分类器。
4. **可移植的产物：** 稳定的 JSON 快照和一份自包含的 HTML 报告。
5. **小表面：** 一个 Python 包，以标准库为核心，不起 Web 服务。

## v0.1 不做的事

- 实时 MCP 进程或 HTTP 抓包
- 完整的 JSON Schema 实现
- 输出符合性测试
- LLM 行为评估
- 自动提升 baseline
- 托管式的历史记录或协作
